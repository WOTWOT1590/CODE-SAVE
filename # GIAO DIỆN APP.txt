# CẤU TRÚC 
Có 3 giao diện, màn hình:
+ 1. Giao diện Home 
+ 2. Giao diện Function
+ 3. Giao diện RealTime
Chi tiết all giao diện 
+ Giao diện Home
- Hiển thị logo, tên app
- Nút Mở game, FF, FFMAX 
- Nút chuyển đến link facebook, zalo dev/admin
+ Giao diện Function
- Có 7 Chức năng:
Tối ưu máy
Buff fps
DNS
Tối ưu Game
Ping
Giảm đồ họa game
BUFF PING SERVER 
chức năng chi tiết t cấp sau
+ Giao diện RealTime
- Có 2 bảng thống kê fps,ping từng giây (sẽ có ảnh minh họa)
- Có 4 nút Optimize FPS, Optimize GAME, Dọn RAM/Cache, Tối ưu CPU/GPU
# LUỒNG TƯƠNG TÁC
- Khi người dùng bật/tắt (Toggle) một chức năng trong tab Function thì sẽ có hiệu ứng rung/đổi màu đặc biệt trên giao diện
